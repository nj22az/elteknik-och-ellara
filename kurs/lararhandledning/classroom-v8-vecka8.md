# Classroom-inlägg vecka 8 — 9.1 Ritningar

Klistra in som det står. Bara 9.1, inte m10. Inte quiz/slides (kommer senare).

---

Välkommen till vecka 8: ritningar och måttsättning, på papper — inte live för att gissa, inte 440-lucka för att stämma av ritningen. Läs lektion 9.1 innan du lämnar. Elektriker: hitta N på enlinjen — den kanske inte finns. Ingenjörer: ritning först, durk sen. I Classroom ligger enlinje, kretsschema och en skiss med ett satt mått och ett tomt. Fyll: märk enlinje mot kretsschema, peka huvudtavla, grupp och motor, avläs det satta måttet och flagga det tomma, och 440 på ritningen = look-not-touch. Inte m10, inte “jag kan anläggningen”, inte mäta live för att fylla luckan.
